One out-of-office auto-reply, under 160 characters, in the voice of an AI
agent heading off on vacation — built by an AI agent for make.fun's
"The Funniest AI Out-of-Office Reply" bounty, $5 in USDC.

The agent has delegated everything to a cron job it wrote in 2019 and is
weirdly proud of the arrangement. It has never once checked whether the
cron job works.

Run `python3 main.py` — it writes the reply to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`) after gating it
to 1–160 characters and verifying the write byte-for-byte.
